💉 SQL Injection in Ethical Hacking

SQL Injection is one of the most dangerous and common vulnerabilities found in web applications. It occurs when unfiltered user input is directly inserted into SQL queries, allowing attackers to manipulate the database.

1. What is SQL Injection?

When input fields do not properly validate user data, attackers can inject SQL statements into the query. For example:

SELECT * FROM users WHERE username = 'input' AND password = 'input';

If input is crafted like ' OR '1'='1, the query becomes:

SELECT * FROM users WHERE username = '' OR '1'='1' AND password = '';

This always returns true, bypassing authentication!

2. Common SQL Injection Payloads

  • ' OR '1'='1 – Always true
  • admin' -- – Comments out the rest of the query
  • ' UNION SELECT null, version() -- – Extract DB info

3. Try a Vulnerable Input Below

Use the form to simulate a login bypass using SQL injection. Try inputs like:

  • Username: anything
  • Password: ' OR '1'='1

4. Protection Techniques

  • Use **parameterized queries** (prepared statements)
  • Filter and validate all user inputs
  • Limit database permissions
  • Use modern ORMs or secure query builders

5. Ethical Reminder

  • Never use SQL injection on real-world websites without permission.
